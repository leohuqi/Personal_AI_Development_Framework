# 同任务阅读对照

这里只比较文档组织方式：相同中性合成Feature `SYN-FULL-F01`，相同事实正文、问题、模型和预算；旧臂将全部正文拼接成一份材料，新臂保留分层入口。它不代表旧版PADF已存在这份产品设计，也不能将样例结果推广为真实项目成本收益。

`python3 examples/architecture-method/validation/prepare-reader.py <不存在的临时输出目录>` 从当前Full样例生成两份独立包与来源hash。两位全新真实Agent分别只通过生成的 `reader.py old|new list` 或 `read path first_line last_line` 读取自己的包，每位最多10次请求/24000返回字符；辅助器保存逐次真实输入路径、行号、返回内容和计数。该限制依赖任务指令和可核验调用，不声称是操作系统隔离。超预算截断如实记录。

两臂收到同一个问题：为可靠接管文件的Feature找出准确设计基线及批准状态、模块职责/接口、数据/权限规则、失败恢复、验收和未测项、尚未批准的决定；给来源，不设计新行为或编码。读者不能看到另一臂答案、作者解释、评分表或期望结论。两份原始答案完成后才比较覆盖和遗漏，不以字符数计算Token/时间百分比。语义独立Review和真实产品实施分别验证。
