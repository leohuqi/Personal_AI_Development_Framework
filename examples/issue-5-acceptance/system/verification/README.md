# Reproduction sources
These are the exact authoring-host scripts used for the diagrams, browser test run and package/source comparison. They supplement immutable visual source 123aa014962289feccf527f8e063a19299c1e975; they do not change it. The first two script SHA-256s match ARTIFACT-MANIFEST.json at that source.

- author-diagrams.py: deterministic HTML/inline-SVG source authoring under loaded diagram-design instructions. Run from a scratch workspace root with Python 3. It creates outputs/issue-5/system/. No external dependencies/network calls.
- verify-browser.cjs: actual 15-group browser checks and PNG captures. Requires Node.js, Playwright and installed Chrome. The absolute require/executable paths are the authoring host paths recorded in the source. On another host change only those two path literals to the available Playwright module and Chrome executable. Run from the same scratch workspace root; it reads/writes outputs/issue-5/system/. It tests real browser events, not simulated claims.
- check-and-package.py: expands aggregate package edges, checks exact approved graph equality and writes README/style/manifests. It needs immutable SYSTEM-BASELINE.md and SYSTEM-MODEL.json downloaded from f4dbf0d3fac707db1b57252c529618c38d26f0bc under work/system-visuals/sources/ and the first two exact scripts under work/system-visuals/generate.py and verify.cjs. The packager filename itself is not referenced by its output.

To reproduce only browser verification, copy the published visual files into outputs/issue-5/system/ and run the supplied browser script after mapping local tool paths. To independently verify SVG exports, use pinned diagram-design scripts/export_svg.py --system-fonts on each standalone HTML; self_check.py --offline and scripts/verify-geometry.py commands/results are in skill-check-report.json.

Authoring/check scripts stay outside the visual UI. No package installation is performed. Existing screenshot hashes identify the actual tested authoring-host renders; another browser/font platform can produce different pixels. Independent Reviewer must read the approved requirements and inspect actual sources rather than adopt the author's test conclusions.
