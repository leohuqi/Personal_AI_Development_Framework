# 产品与设计依据

## create-item

REQ-101：团队需要记录待办事项。AC-101：合法标题创建成功；重复请求不能重复创建。REQ-102：负责人可以接收工作项。AC-102：分配后显示负责人，越权分配被拒绝。

## assign-owner

EX-F102引用同一个REQ-102和AC-102，不复制另一份要求正文。

## design

DESIGN-101：服务端创建/分配接口复用已有身份校验，持久化后返回对象标识；幂等键防止重复创建。此为合成当前候选设计v2，未获批准。仅有[标题校验辅助函数](sample.py)的局部实现依据；创建、持久化、身份、分配及幂等的业务实现仍缺，不能据此宣称整个功能已实现。
