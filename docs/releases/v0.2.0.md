## Highlights

PADF V0.2 introduces **task-centered, cross-session context and agent communication contracts**, designed for ChatGPT, Work, Codex and future specialized agents without making chat history a source of truth.

- **Context Coordinator Skill:** locate minimal authoritative task context, handle message persistence, checkpoint, resume, handoff and conflict escalation.
- **Shared Task Context:** reference GitHub specs/ADRs/code, Linear task state, approval evidence and linked artifacts without duplicating the whole project.
- **Agent Message Protocol:** structured requests, responses, blockers, findings and handoffs with message/thread IDs, lifecycle, durable links and idempotency.
- **Checkpoint & Resume:** preserve last observed Git/spec versions, completed evidence, pending messages and authorized next action; reject stale/unapproved resumes.
- **Agent Handoff Contract:** cross-role artifacts, exact SHA and verification status with acknowledgement/needs-refinement controls.
- **Governance:** clear Owner authorization, source-of-truth and independent-review boundaries.
- **Validation:** structural checker, cross-process protocol fixture, regression tests and GitHub Actions workflow.

## Scope / limitations

This release provides **Skills, contracts, documentation and validation utilities**, not an always-on agent runtime. There is **no** automatic message delivery guarantee, autonomous dispatch, agent wake-up, new database/message broker, A2A server, auto-merge or production deployment. Live Linear integration and PQA adoption are follow-on tasks requiring separate authorization.

**PQA Draft PR #7 was not modified by this release.**
