# PADF v0.3.2 版本变更

本补丁统一 Master 的持续分派授权：已批准范围内可使用现成真实 Agent 运行时自动分派、启动与接续，无需新增逐次 Owner 批准。实现来自 [PR #10](https://github.com/leohuqi/Personal_AI_Development_Framework/pull/10)，不新增后台调度器或运行时服务。

## 变更

- 同步 AGENTS.md、审批策略、Master Skill、Dispatch 契约、验证手册及相关 Task Contract、模板和工作流。
- 增加只读 `evaluateDispatchAuthorization`：有效批准范围内的分析、设计提案、基线内设计、测试、审查和协调可继续；逐次核对仓库、上下文、精确 Task Contract、环境、范围项、角色/动作和必要决策版本。
- 授权撤销、范围漂移、缺少必要 SYSTEM/UI 决策或错误批准版本时阻断；业务编码、重大决策批准、合并、发布、生产部署、破坏性操作和最终验收不能继承分派授权。
- 修复首轮独立审查发现的 context-coordinator 合法 COORDINATE 任务误阻断；加入合法协调、范围不允许及运行时证据缺失的回归。
- 保留 Dispatch → 独立 Execution → Handoff → Master Dependency Reconciliation，真实 task/run ID 必须来自工具；HUMAN_RELAY 与角色模拟不冒充 RUNTIME_DISPATCH。

## 接入与兼容

既有 `padf.agent-dispatch/v1` 和其他通信/设计契约保留；新增可选的 `padf.dispatch-authorization/v1` 快照，不将历史证据或缓存批准自动转换为有效授权。接入项目固定 v0.3.2 或精确 SHA，同步受影响 Skill、治理、契约、工作流、校验器和测试；已有授权必须实时核对权限、范围与版本，不能自行补造。

评估器仅验证调用方已核验快照的一致性，不认证 Owner、不授予运行时权限、不启动 Agent。DESIGN_READY 仍不代表编码授权，框架发布不自动升级 PQA 或批准其他项目的实现、合并、发布及生产操作。v0.3.1 及更早标签保持原样。
