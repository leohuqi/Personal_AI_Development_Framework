# 小团队协作：明确责任，减少交接负担

适用于 Owner 加 1–2 名技术成员，也可用于个人与多个 Agent 协作。复用现有仓库、Issue/PR、对话及 Agent 工具，不安装 BMAD，不新增服务。角色是工作职责，不是必须配齐的人数或会话数。

## 谁负责什么

| 参与者 | 负责成果 | 可以决定 / 必须升级 |
| --- | --- | --- |
| Owner / PM | 目标、产品范围、优先级、里程碑、业务验收 | 保留最终决定；重大产品/UX/架构、风险接受、编码范围、合并、发布、生产及破坏性操作按原政策批准 |
| 技术负责人（可兼开发） | 技术方案、复杂度与依赖、接口协调、技术审查、集成和上线准备 | 在批准基线内选择常规实现；改变范围、重大架构、成本或承诺时交 Master 汇总给 Owner |
| 开发 / 集成 / 部署执行者（可兼任） | 实现、测试、双方联测、获批准版本的部署和检查 | 在授权范围执行；部署执行责任不授予上线决定权，故障处理按获批准运行手册的边界进行 |
| Master Agent | 拆分与协调、收件、整体一致性、进度、统一成果及待决入口 | 安排已授权工作并退修；不代 Owner 决定，不代专家或独立 Reviewer 出具结果 |

每项任务指定一位真人交付负责人，另写实际执行者（人或 Agent）、审查者和批准人；同一个人可以兼任多个工作角色，但实现者不能自认独立审查者。Agent 记录真实工具执行 ID；真人记录姓名/账号、实际动作和证据，不编造 Agent 会话或运行 ID。当前机器门禁不因此获得真人身份认证能力，不能把人工记录伪装成 RUNTIME_DISPATCH。

## 从一个任务推进，不建立多份台账

1. Owner 批准明确范围及所需授权；Master 在现有 Issue/PR 放一份[最小 Task Contract](../contracts/task-contract.md)，指定责任和必要角色。有效授权内的分派、返工、重试不逐次重新申请。
2. 目标和行为已明确的局部任务复用基线；有产品缺口才补 PA，有系统决定才补 SA，需要实施细化才由 Module Designer 接收。简单任务可由同一执行者合并两阶段规格，但保留必要内容、裁剪理由及独立审查。
3. 成员各自用分支/隔离工作区及自己的 Agent，避免同时改同一活动目录。跨成员的成果、决定和阻塞回写共享任务；本地聊天不自动共享。
4. 交接只回答[六个问题](../contracts/agent-handoff.md)，接收方实际核验后回复 ACK 或指出具体缺口。Master 协调可写在原线程，不必让每份文档都“经过 Master 再复制一遍”。
5. CI、适用 QA、独立审查通过后，把成果与待决项交 Owner；合并、验收、发布和生产各自核验。指定成员执行获批准上线，回报版本、上线检查、恢复能力和后续运维负责人。

真人可以直接承担技术或接口工作；需要证明正式 Agent 编排时，仍须完整真实执行链。缺少独立 Agent 运行能力不能用角色扮演补证；所需独立审查缺失时保留 BLOCKED，并选择真实独立会话或项目明确支持的人工审查路径。

## 跨系统与生产：只增加必要内容

- 接口任务：双方责任人、精确接口版本、业务含义/权限/错误与兼容约定、联测环境和通过标准。新接口要求影响产品范围时由 Owner 决定。分别报告本方测试、双方联测和生产连通，未执行不写 PASS。
- 生产任务：准确发布版本/产物、环境及配置/迁移影响、部署与回滚/恢复手册、上线检查、操作和运维负责人；执行者只能部署被批准范围。现有 [G-01](../contracts/action-preflight.md) 仍适用。
- 框架规范不是平台权限设置。仓库和生产环境的权限、凭据、审批及防绕过措施由接入项目配置，不能因文档已写就宣称生效。

## 人需要看的内容

所有角色向人请求审查或决定时，用[阶段交付模板](../templates/stage-delivery.md)的短卡片：需要谁判断什么、推荐及理由、影响/风险、可直接回复的选项、成果版本。完整方案和审计在链接后按需展开；重大风险不能藏进附录。技术成员审查技术，Owner 判断产品取舍与授权，不要求 Owner 阅读机器字段或替 Agent 研究常规实现。

例如“新增外部订单查询”可以这样请求：

> 请技术负责人确认：外部接口是否支持按订单号查询及当前错误码？建议先交付手动查询，暂缓自动同步，减少接口和运维成本。确认后由开发实现、双方联测；产品是否需要自动同步由 Owner 另行决定。接口草案与来源版本见任务链接。

回复“收到”不是批准；技术确认也不等于产品验收或生产授权。Master 记录实际原话、事项、版本和范围，缺少会影响决定的答案时只暂停依赖部分。
